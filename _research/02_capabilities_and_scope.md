Пик пришёлся на 2026-09-05..09-08, в те же дни, когда писались ADR 0007–0011. После 09-10
активность почти нулевая. `[ВЫВОД]`: инструмент использовался в основном как **песочница для

## 3. Аудит объёма после ADR 0006

**Критерий решения.** Помогает ли возможность владельцу, который ведёт 3–5 интерактивных сессий над
agent-desk и ai-worker, *видеть и не терять нить*? Или она делает то, что лучше делает нативный
CLI либо ai-worker? Отдельный вес: безопасность при самодогфудинге.

| Возможность | Решение | Обоснование |
|---|---|---|
| Запуск агента по клику (0006) | **Оставить за флагом, заморозить** (по умолчанию выключено на уровне приложения) | Единственная «исполняющая» функция с живыми данными (25 задач, 8 успешных). Но это тонкая обёртка над `claude --bg -w` и `claude agents`, которые CLI уже даёт `[ФАКТ: claude --help, 2.1.283]`. Передавать ai-worker нечего: ai-worker работает от тикетов Jira, а не от строки в консоли. Не развивать: #7, #9–#11, #19 сливать только как исправления |
| Autostart (0007) | **За флагом, заморозить** | Уже выключен в обоих проектах. Автоматическое «когда» над задачами — это то, что ai-worker делает по тикетам (watcher/poller). Для локальной работы не нужно, пока нет очереди |
| Explore и автослияние с push (0008) | **Удалить из agent-desk.** Концептуально это территория ai-worker | Агент сам находит работу, сливает и **пушит** при зелёном гейте (`land.py:195`, по умолчанию `push=True`). Этот гейт не герметичен (04 §G1). Использовано 6 раз, 0 слияний. ai-worker свою автономную полосу выпустил *отказывающей* (ADR 0017@DuckyFlow). В agent-desk та же идея без Sentinel. Если нужно, возвращать только через ai-worker |
| Kicking (0009) | **Удалить** или жёсткий флаг с остановленным циклом | 0 использований. Это единственный путь, который пишет в контекст работающей сессии по таймеру, пусть и «включённый человеком». Против правила №1 по духу. Цикл стартует всегда (`web/app.py:143`) |
| Закрытие сессий (0012) | **Удалить** | Единственное необратимое действие (сам ADR 0012 говорит об этом), 0 использований, 0 канареек. `claude stop`/`claude rm` делают то же вручную |
| Запись в Jira (0005) | **Заморозить за флагом** | Вживую не использовалась (259 строк `filing` фальшивые). Правильный мост к ai-worker — **черновик тикета**, который человек сам заводит в Jira (DuckyFlow `docs/17-deferred.md:218-239` откладывает «приём не из тикета»). Действие «черновик» уже есть в инбоксе |
| Чтение Jira-доски (0010) | **Удалить часть про Jira**, это передаётся ai-worker | 0 использований; тикеты — источник правды ai-worker, и его экран «Tickets» уже сортирует по ожиданию |
| Чтение PR GitHub (0010) | **Оставить за флагом, включить для двух своих репозиториев** | Дёшево и полезно при долге слияния: «какие PR висят и сколько». Только чтение |
| MCP-сервер | **Оставить и подключить**, сначала исправить R1 | `keep_idea` и `ask` из сессии — самый дешёвый по контексту путь в инбокс, тот самый вопрос №3 из `docs/01-vision.md`. Но сейчас открытие MCP-сервера валит незавершённые блоки консоли (`mcp/server.py:131`, `store/repo.py:1175`) |
| Верстак: поверхность и карточки (0011) | **Оставить за флагом, заморозить** | Лёгкое использование (233 карточки), 3,3 тыс. строк JS без исполняемых тестов. См. `03_workbench.md` |
| Движок прогонов, шаблоны, инструменты, проверки, оценка, рисунки (0011, `docs/12`) | **Заморозить за флагом**, код не удалять | 0 прогонов, 0 рисунков, 0 оценок. Удалять жалко, развивать нет данных. Флаг убирает их из UI и не стартует `engine.run` |
| Фоновая оценка идей | **Добавить выключатель, по умолчанию выключено** | Тратит деньги без клика человека, каждые 15 минут, пока консоль открыта. При пустом инбоксе расходы нулевые, но правило «модель вызывается по действию человека» лучше соблюдать явно |
| Общий вид (фаза 4) | Оставить как есть (выключено) | Второй человек (друг) может получить доступ к списку идей. См. 07, В5 |

**Итог по объёму.** Ядро на каждый день — доска, инбокс, блоки, MCP-вход в инбокс, расходы и
журнал смены. Всё, что *исполняет* или *решает*, уходит за один флаг `AGENT_DESK_HANDS=off` с
выключенными по умолчанию циклами autostart, kicking и engine. Ещё три возможности удаляются:
explore/land, kicking, закрытие сессий. Это возвращает проект к `docs/01-vision.md:47`: «It does
not run agents… It observes and it remembers». Флаг оставляет обратный путь без переписывания
ADR 0006–0012 `[ВЫВОД]`.

По оценке, удаление трёх возможностей убирает примерно 1,5–2 тыс. строк кода и тестов (`tidying.py`,
`web/kicking.py` без appraise, `land.py`, `dispatch.go_looking`, связанные маршруты)
`[ДОПУЩЕНИЕ: не измерено построчно]`.
