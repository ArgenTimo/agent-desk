### Находки

- **G1 (высокая), запуск.** Набор тестов не изолирован. С фейковым `claude` в PATH насчитано
  18 вызовов из 12 тестов.
  - Один из них — `claude --bg --worktree beri-v-rabotu "бери в работу…"` из
    `test_a_prompt_that_is_measured.py::test_pressing_one_of_the_kinds_is_a_label`. Это и есть
    происхождение 7 worktree `beri-v-rabotu*`.
  - `test_laying_out.py:56` делает `routes.store.open()` на настоящем пути: миграции ветки плюс
    `_recover_interrupted` на живой БД.
  - Два теста пишут настоящий `secrets.json`.
  - Исправление в неслитом #14/#21 закрывает только `claude`, но не `data_dir`.
- **R1 (высокая), чтение.** Любой `Store.open()` считает, что он единственный процесс на файле. MCP-сервер
  (`mcp/server.py:131`), второй экземпляр, тест из G1 и перезапуск через `--reload` роняют
  бегущие блоки консоли.
- **R2 (высокая), БД.** Живая БД содержит версии 1..79 подряд. Её 78 — это `changed_at` из ветки
  `card-changed-at`, её 79 — `sketch_card` из worktree `draw-what-the-project-is`, её 66 нет ни в
  одном ref. У `origin/main` 066 нет, а 078 — другой файл. **Следующую миграцию `079` из `main`
  живая БД молча пропустит**, и ошибка всплывёт во время работы в каком-нибудь маршруте.
- **R3 (средняя), чтение.** Рабочий экземпляр — это dev-сервер с `--reload` из копии, в которую
  `land` мержит, а сессии коммитят.

### Требования к надёжности для «пользуюсь каждый день»

1. **Рабочий экземпляр отделён от кода, который правится.**
   - Отдельная копия `~/opt/agent-desk-prod`, закреплённая на теге `desk-YYYYMMDD`.
   - Запуск через `systemd --user`, `python -m agent_desk` без `--reload`, `Restart=on-failure`.
   - Логи в journald.
   - Обновление — осознанный `git checkout <tag> && systemctl --user restart agent-desk`.
2. **Dev-экземпляры никогда не видят рабочую БД.**
   - `conftest` и `make run` из любого worktree по умолчанию получают `AGENT_DESK_DATA_DIR`
     внутри worktree (например `.desk-data/`) и другой порт.
   - Рабочий путь включается только явной переменной.
3. **Миграции безопасны на живых данных.**
   - Копия `agent-desk.db` → `agent-desk.db.bak-v<N>` перед применением.
   - Таблица версий хранит **имя файла**. Старт отказывает, если применено имя, которого код не
     знает, или если номер совпадает, а имя нет.
   - Одноразовая сверка текущей живой БД (78/79/66).
4. **Один процесс — одна БД.** Файловая блокировка (`fcntl.flock` на `data_dir/.lock`) для
   консоли. MCP-сервер открывает store **без** `_recover_interrupted`.
5. **Откат — это тег кода плюс файл бэкапа.** Задокументировать двумя командами в README.
6. **Запасной путь через терминал описан, а не придуман в момент аварии.**
   - `claude agents` показывает сессии и фоновые задания.
   - `claude attach <id>` — ответить.
   - `python -c "import sqlite3…"` или `poetry run python -m agent_desk.mcp` — прочитать инбокс
     без веба. Инструменты `open_ideas` и `idea` работают без консоли (чтение `mcp/server.py`).
7. **Признак жизни.** `/health`, который ругается, если цикл SSE не тикал дольше N секунд, и
   `systemd` `WatchdogSec` по желанию.
